# Kanagata

PC から Notion を閲覧できる Next.js アプリです。お小遣い管理機能も備えています。

## セットアップ

```bash
npm install
cp .env.local.example .env.local  # 値を設定する
npm run dev
```

## 環境変数

| 変数 | 説明 |
| --- | --- |
| `NOTION_API_KEY` | Notion インテグレーションのトークン |
| `NOTION_DATABASE_ID` | ページ一覧に表示する Notion データベースの ID |
| `NOTION_ALLOWANCE_DATABASE_ID` | お小遣い台帳の Notion データベースの ID |

## お小遣い管理のセットアップ

お小遣いのデータは Notion のデータベースに保存されます。以下の手順で準備してください。

1. Notion で新しいデータベース（テーブル）を作成し、名前を「お小遣い台帳」などにする
2. プロパティを次のとおり設定する（**名前と種類を正確に合わせてください**）

   | プロパティ名 | 種類 | 備考 |
   | --- | --- | --- |
   | 項目 | タイトル | 買ったもの・収入の名前 |
   | 日付 | 日付 | |
   | 金額 | 数値 | 円単位 |
   | 種別 | セレクト | 選択肢: `収入` / `支出` |
   | カテゴリ | セレクト | 選択肢: `食費` / `趣味` / `交際費` / `日用品` / `貯金` / `その他` |
   | メモ | テキスト | 任意 |

3. データベースをインテグレーションと共有する（データベース右上の「…」→「接続」→ 使用中のインテグレーションを追加）
4. データベースの ID（URL の `notion.so/` 以降、`?` より前の 32 文字）を `.env.local` の `NOTION_ALLOWANCE_DATABASE_ID` に設定する
5. アプリを起動し、サイドバーの「お小遣い管理」を開く

### できること

- 収入・支出の記録（アプリから Notion に書き込み）
- 残高（全期間の収入 − 支出）と月ごとの収入・支出の表示
- 月別の履歴一覧（← / → で月を移動）
- カテゴリ別の支出内訳（横棒グラフ）

データ本体は Notion にあるため、スマホの Notion アプリからも閲覧・編集できます。
